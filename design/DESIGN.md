# 広尾親父RC デザインルール v1.3（2026-11-08）

AI（Claude）に「ページを作って」「ここを直して」と頼んでも、見た目がブレないようにするための決まりです。
人が読んでも、AI が読んでも、同じ結論になるように書いています。

| ファイル | 役割 |
|---|---|
| `hg.css` | **正本**。色・文字・余白・部品はすべてここ |
| `design/DESIGN.md` | このファイル。考え方と使い方 |
| `design/catalog.html` | 見本帳。部品の見た目を目で確かめる |
| `design/check.py` | 点検。ルールから外れている数を数える |
| `design/hg_page.py` | ページの雛形。頭・合言葉の扉・ボットを毎回同じにする |
| `hg-auth.js` | 合言葉の扉（共通）。合言葉を変えるときはここの `PASS` だけ直す |

---

## 1. 今どうなっているか（2026-11-08 時点の点検結果）

- 22ページすべてが、自分の中に色と部品を個別に持っている。共通のスタイルファイルがない
- 色コードの直書き **2,240か所**、上書き（`!important`）**188か所**
- 見た目が **3層の重ね塗り**になっている
  1. 最初の層：明るい緑 `#1B5E35` ＋金 `#C9A227`、ゴシック体
  2. `gold-theme`：大理石の背景と金縁を `!important` で上から塗った
  3. `tora-theme`（金縁の実録帖）：深い緑 `#1B4030`・金 `#C3A24D`・生成り `#F7F3E8`、明朝と Cinzel をさらに上から塗った
- 層の載り方がページでバラバラ。`about` と募集ページは1層目のまま、物語ページは2層目まで、虎の巻は3層目
- 金色の小さい英字ラベル（`#A8873C` を生成りの地に）は文字と地の差が 3.1 しかなく、読みにくい（目安は 4.5 以上）

**真因**：AI にページを頼むたびに「そのページの中だけで」見た目を足してきた。正本がないので、AI は直すたびに上から塗るしかなかった。

## 2. 考え方（AI駆動デザインの7原則）

1. **正本は1つ**
   色・文字・部品は `hg.css` だけで決める。ページの中に `#xxxxxx` を書かない。`var(--hg-…)` を使う。
2. **上から塗らない**
   見た目を変えたいときは、ページで上書きしない。`hg.css` を直す。直せば全ページが同時に変わる。
3. **部品の名前で頼む**
   「緑っぽい箱を3つ」ではなく「金縁カードを3枚」と頼む。部品は下の表にあるものだけ使う。
4. **色は役割で選ぶ**
   「金色」ではなく「金の線」「紙の上の金文字」で選ぶ。同じ金でも、線に使う色と文字に使う色は別。
5. **新しい部品は、先に正本へ足す**
   今の部品で足りないときは、ページに直接作らない。`hg.css` と見本帳に足してから使う。
6. **飾りより中身**
   見出しの上のラベルは**日本語で中身を言う**（「活動内容」「よくある質問」）。英字の飾りラベル（ABOUT など）は付けない。何でもカードにしない（予定は罫線リスト、自己点検はチェックリスト）。目立たせるのは1ページに1か所。画面に入るとふわっと出る動き（`.hg-fade`）も1ページ1か所まで。
7. **点検は数字で**
   `python3 design/check.py` の「直書き色」「上書き」「テーマ層」を 0 にする。0 になったページに ◎ が付く。

## 4. 文字

| 種類 | 書体 | 使うところ |
|---|---|---|
| 日本語の見出し | しっぽり明朝 `--hg-font-head` | 扉の大見出し・節の見出し・カードの題 |
| 欧文の飾り | Cinzel `--hg-font-label` | 「Q」などの欧文1〜2文字だけ。ラベルや見出しには使わない |
| 本文・ラベル | ヒラギノ角ゴ `--hg-font-body` | 本文、見出しの上のラベル（太字・字間少し広め）、バッジ |

大きさは `11 / 13 / 15 / 18 / 22` の5段と、扉の大見出しだけ（`--hg-fs-xs`〜`--hg-fs-xl`、`--hg-fs-hero`）。
余白は 4 の倍数（`--hg-s1`〜`--hg-s7`）。角の丸みは 4種類（`--hg-r-sm/md/lg/pill`）。

### 合言葉の扉

部員専用のページは `<body class="hg">` の直後に `<script src="./hg-auth.js"></script>` を1行置くだけ。見た目は hg.css の `.hg-auth`。ページに扉を書かない。`design/hg_page.py` の `page(..., auth=True)` を使えば自動で入る。

### ページだけの部品（正本に入れる候補）

各ページの `<style>` に、`var(--hg-…)` だけで書いたそのページ専用の部品がある（`races-item`、`history-row`、`garmin-battery` など）。2ページ以上で同じ形が出てきたら正本に移す。

## 6. AI への頼み方（Claude はこの手順で動く）

**新しいページを作るとき**
1. このファイルと `design/catalog.html` を読む
2. `design/hg_page.py` の `page()` で組む（Google Fonts・`hg.css`・合言葉の扉・ボットが自動で入る）
3. 部品の表にあるものだけで組む。ページ内の `<style>` は配置（並べ方）だけに使い、色・書体・大きさは書かない
4. `python3 design/check.py 新しいページ.html` で ◎ を確かめてから渡す

**直すとき**
- 見た目の変更は `hg.css` を直す。そのページだけ変えたいという頼みでも、まず「部品を足すか、今の部品で足りるか」を確かめる
- 部品が足りないときは、`hg.css` → 見本帳 → この表、の順に足してから使う

**頼む側（人）の言い方の例**
- 「ラン虎の巻に、金縁カードで給水のコツを3枚足して。タグは鉄則1枚、あとはふつう」
- 「募集ページの締めを暗い節にして、ボタンは LINE で聞く、の1つだけ」

## 7. 移行の進め方

| 段 | やること | 確かめ方 |
|---|---|---|
| 1（済） | 正本・見本帳・点検をつくる | 見本帳を目で見て判定 |
| 2（済） | 1層目のままの `about.html` を試しに移す | `check.py` で ◎（直書き色 52→0）、見た目を判定 |
| 3（済） | 虎の巻5本。`design/migrate_guide.py` の対応表で一括変換 | 5本とも ◎（直書き色 760→0）。文章は英字ラベル以外すべてそのまま |
| 4（済） | 合言葉の扉を `hg-auth.js` に共通化。トップ・奮闘記・痛み撲滅・マニュアル・筋トレ・ガーミン・リンク集 | 移したページはすべて ◎ |
| 5（済） | レース表2本・活動アーカイブ。絞り込みと検索は移行前と同じ結果になることを確かめた | ◎ |
| 整理（済） | 募集ページ2本（`recruit_a` `recruit_b`）を削除。リンクのない古い下書きで、消したはずの表記が残っていた | ― |

1ページずつ移し、そのたびに `check.py` の数字が下がることを確かめます。
